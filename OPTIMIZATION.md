# Оптимизация сайта

- 59 PNG конвертированы в WebP lossless без изменения разрешения. Проверены альфа-канал и все RGB-пиксели, имеющие ненулевую прозрачность. RGB полностью прозрачных пикселей не влияет на изображение.
- Общий размер этих файлов: 108 280 992 → 61 884 342 байта (−42,8%). Подробности: `artifacts/image-optimization.json`.
- Исходники сохранены. Конфигурация Vite исключает их из публикации, а также исключает служебные JSON и неиспользуемые версии трёх фонов. Ранее подготовленные WebP-фоны не пересжимаются.
- Изображения разделов загружаются по мере прокрутки, декодируются асинхронно. Изображение прелоадера имеет высокий приоритет.
- Каталог техники вынесен в динамический модуль: основной JS 562,02 → 537,18 КБ. 3D-просмотрщик, как и прежде, импортируется только при необходимости.
- Из `main.jsx` удалены неиспользуемые старые экраны, данные, импорты и обработчик движения мыши для отсутствующего Hero. Из каталога удалён устаревший неиспользуемый набор данных. На устройствах без точного указателя не устанавливаются обработчики курсора.
- Итоговая сборка: 68 308 848 байт. Это размер всех файлов, включая каталоги и 3D-модели, а не объём первой загрузки.

## Повторная подготовка

1. `npm run optimize:images` — конвертация PNG и проверка совпадения пикселей.
2. `npm run build` — подготовка `dist` с оптимизированными ресурсами.
3. `npm run preview -- --host 127.0.0.1 --port 4173`.
4. `npm run test:optimization` — проверка готовой сборки на экранах 1440 и 390 px. Другой адрес задаётся через `BASE_URL`.

Проверены прелоадер, изображения разделов, все шесть категорий каталога и открытие деталей; дополнительно проверены слои карты, сравнение, полноэкранный режим и иллюстрации самолётов. Ошибок JS или HTTP не обнаружено. Некоторые прежние сценарии тестов имеют устаревшие ожидания: например, ожидают один слой фоновой карты, тогда как текущая разметка содержит два, или отсутствие внутренних ссылок, которые уже есть на странице.

Минимальное время прелоадера осталось около 7 секунд согласно выбранному ранее поведению; оптимизация ресурсов не сокращает эту намеренную задержку.
