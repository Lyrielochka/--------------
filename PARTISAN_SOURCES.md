# Партизанская карта: источники и точность

В `src/partisanEvents.js` находятся 25 записей за май–июль 1944 года. Основной корпус — [оперативные сводки Белорусского штаба партизанского движения](https://docs.historyrussia.org/ru/nodes/296581?view=grid), опубликованные Национальным архивом Республики Беларусь. Для каждой записи сохранена ссылка на карточку документа. Отдельное донесение 122-го полка [опубликовано здесь](https://docs.historyrussia.org/ru/nodes/332074-boevoe-donesenie-locale-nil-01-shtaba-122-go-partizanskogo-polka-locale-nil-za-rodinu-locale-nil-voenno-operativnoy-gruppy-pri-belynichskom-podpolnom-raykome-kp-b-b-o-podgotovke-i-provedenii-operatsii-po-podryvu-relsov-na-zheleznoy-doroge-23-iyunya-1944-g).

`coordinates` задают ориентир для показа названного населённого пункта, участка или района на современной основе карты. Они **не являются архивными координатами диверсий**. `coordinateAccuracy` различает приблизительное место, участок и район. Для двух партизанских зон показан условный ореол, а для линии Лунинец — Барановичи — схематический коридор между названными городами; они не воспроизводят историческую границу зоны или точное положение путей.

Если документ сообщает лишь дату сводки, в `dateLabel` это оговорено. ISO поле `date` используется для месячного фильтра и сортировки; оно не всегда означает точный день события. Формирование не названо по имени, когда доступный фрагмент источника этого не подтверждает. Фильтры «Разведка» и «Связь» пока могут быть пустыми: локализованные эпизоды этих типов требуют дальнейшей проверки по полным документам. Новые карточки следует добавлять только после сверки даты, географии, формирования и результата с текстом источника.
