# Локальный сайт с нейросетью

1. Запустите Ollama. Модель `qwen3:8b` уже установлена.
2. Дважды нажмите `Запустить сайт с Мурвиком.cmd` в этой папке.
3. Дождитесь открытия браузера: http://127.0.0.1:4173.
4. Откройте Мурвiка и вкладку «Спросить Мурвiка». Статус `Ollama · qwen3:8b` означает, что локальная модель доступна.

Оставьте окно запуска и Ollama работающими. Остановка сайта — Ctrl+C в окне запуска. Модель при первом вопросе загружается в память, поэтому первый ответ может быть медленнее. Ответы ограничены по длине и читаются по страницам. Если сервер или модель недоступны, помощник использует подготовленные ответы; в карточке указано, какой режим ответил.

Сервер слушает только 127.0.0.1:4173. Интернет, публичный адрес, ключ и настройки роутера не нужны. Другие устройства не получают доступ. Саму Ollama сервер вызывает на 127.0.0.1:11434. Файлы ПК и системные команды модели не доступны.

Исторический контекст подбирается из данных сайта. Последние шесть реплик передаются модели для уточнений. Диалог хранится в памяти страницы и не записывается сервером. Нейросеть может ошибаться: для проверки используйте источники в разделах сайта. Видеоролики и внешние источники требуют интернета.

Через терминал: `npm run local` — сборка и запуск с открытием браузера; `npm run local:server` — только сервер для уже собранного dist. Node.js 22 или новее. Для режима разработки сначала запустите локальный сервер, затем `npm run dev`: Vite перенаправляет запросы помощника на локальный сервер.

Лимиты: один нейросетевой запрос одновременно, до 400 символов в вопросе, ограниченная история, ожидание ответа до двух минут, отмена при очистке диалога. Источники ссылок подбирает сервер, модель не задаёт адреса переходов.

API Ollama: https://docs.ollama.com/api/chat.
