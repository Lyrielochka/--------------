# Отчёт об оптимизации сайта «Операция Багратион»

Дата: 6 ноября 2026 года. Изменения выполнены в локальном проекте, итоговая сборка — в папке dist. Публикация не выполнялась.

## Результат

Все размеры указаны в десятичных МБ (1 МБ = 1 000 000 байт); это размер файлов, а не обещание скорости на конкретном подключении.

Освобождено в сборке: 922,37 МБ. Суммарное число вершин моделей: 16 376 416 → 7 537 024 (−54,0%). Сумма вершин считается по примитивам, а не по уникальным позициям всего каталога.

## Что сделано

1. Геометрия всех моделей сжата Draco; удалены дубли и неиспользуемые данные. Для моделей с более чем 300 000 вершин применено упрощение с целевой долей 40%, ограничением ошибки 0,0005 от радиуса сетки и сохранением границ. Из-за ограничений фактическая доля оставшихся вершин может быть выше целевой.
2. Текстуры моделей ограничены 2048 × 2048 пикселями с сохранением пропорций. Цветовые и прочие текстуры используют WebP с качеством 90; карты нормалей — WebP без потерь после уменьшения разрешения.
3. Декодер Draco включён в сайт. Работа 3D не требует загрузки декодера с внешнего CDN.
4. Кэш просмотрщика уменьшен с пяти до одной неиспользуемой модели, чтобы не удерживать большой каталог в памяти. Уже существующая загрузка GLB только при открытии карточки сохранена и проверена.
5. Подготовлены 45 облегчённых изображений каталога, масштаба и атмосферного фона: WebP, качество 90, прозрачность сохранена, размер до 1600 пикселей по стороне. Ссылки обновлены, включая составные ссылки в разделе обеспечения фронтов.
6. В сборку не попадают тяжёлые lossless-дубли новых изображений и исходные PNG при наличии подготовленной замены.
7. Manrope и Oswald перенесены с Google Fonts в локальные WOFF2 с Unicode-подмножествами и лицензиями OFL. Все файлы шрифтов вместе с лицензиями занимают 0,18 МБ. Внешний запрос CSS Google Fonts убран.
8. Добавлены воспроизводимые команды подготовки ресурсов и проверка всех моделей.

## Проверки

- npm run build — успешно. Сборщик сообщает предупреждения библиотек о директивах use client и крупных JS-файлах; ошибок сборки нет. Крупный просмотрщик 3D загружается отдельно при открытии карточки.
- Все 22 модели проверены в Chrome в итоговой сборке: загрузка, ненулевые размеры, отсутствие ошибок страницы и HTTP, локальный декодер, установленный предел кэша. Отчёт: artifacts/optimized-models-browser.json.
- Для Т-34-85, Т-34-76, СУ-76М и десантной лодки сохранены скриншоты 3D на широком и узком экране. Просмотрены примеры отображения танка, САУ и лодки.
- Основные разделы, изображения и все шесть каталогов проверены на экранах 1440 и 390 пикселей — успешно, без ошибок JavaScript и HTTP. При проверке обнаружены и исправлены три составные ссылки на старые изображения в обеспечении фронтов.
- Проверка загрузки подтверждает: модели не скачиваются при старте, точная геометрия областей отложена, экспорт Минского атласа содержит 76 записей.
- На стартовом экране зарегистрировано около 4,83 МБ ресурсов assets в локальной проверке; сопоставимый замер до изменений не проводился, поэтому процент ускорения старта не заявляется.

## Сохранность и ограничения

Резервные копии всех 22 файлов до обработки находятся в outputs/model-originals/. Промежуточные сжатые копии — в outputs/model-optimized/. Обе папки исключены из Git и публичной сборки. Исходные lossless-изображения сохранены в public; фильтр сборки исключает их при наличии облегчённой версии.

Сжатие цветовых текстур, уменьшение разрешения и упрощение геометрии имеют потери. На обычном размере карточки проверенные примеры сохраняют общий вид, но при сильном приближении мелкие детали могут отличаться. Попиксельная идентичность не заявляется. Самая тяжёлая модель теперь 13,45 МБ. Проверка узкого экрана выполнена в настольном Chrome; физические мобильные устройства не тестировались. Автоматическое парное сравнение с загрузкой тяжёлого оригинала не завершилось из-за закрытия браузера; вывод об абсолютной визуальной идентичности по нему не делается.

Другие изменения, уже находившиеся в рабочей папке до этой задачи, сохранены.

## Повторная подготовка

- npm run optimize:models
- npm run optimize:display
- node scripts/prepare-local-fonts.mjs — требуется доступ к Google Fonts и их официальному репозиторию лицензий.
- npm run build
- BASE_URL задаёт адрес проверяемого локального сервера для npm run test:models, npm run test:optimization и npm run test:loading.

Модельный оптимизатор использует резервные оригиналы, а не многократно сжимает результат. Если рабочая модель была изменена после подготовки резервной копии, он останавливается, защищая новый файл от случайной перезаписи.
