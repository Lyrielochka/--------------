# Операция «Багратион» — интерактивная энциклопедия

## Второй арт-директорский проход

- Кинематографическое вступление с переходом в атлас.
- Закреплённая скролл-история из восьми состояний; при reduced-motion — ручное управление.
- Полноэкранная карта с фокусом на городе и послойным раскрытием сводки.
- Музейная 2.5D-композиция «Лето 1944»: карта, изображение, макет документа и стеклянный слой.
- Горизонтальное путешествие по пяти городам: разные композиции, кнопки, клавиатура и свайпы.
- Сеть тематических связей и геометрический «разрыв времени» между двумя авторскими схемами.
- Отдельный 90-секундный визуальный рассказ без озвучки: пауза, перемотка, лента событий, повтор и выход.
- Три дополнительных механики: выбор исследовательского маршрута, локально сохраняемые отметки и сопоставление двух направлений.
- Архивный стол с перекрывающимися листами и перетаскиванием материала в просмотрщике.

Основные новые компоненты: `src/Cinema.jsx`; визуальная система сцен: `src/cinema.css`. Изменения интегрированы в существующие компоненты, без замены проекта или добавления WebGL.

Хронологическая справка новых сцен: [Военно-исторический музей артиллерии](https://museum-artillery.ru/ru/operacziya-bagration.html). 22 июня во вступлении подписано как канун наступления. Схемы показывают общую идею направлений, а не точные боевые позиции. Сцена 2026 года — авторская визуализация памяти, не современная фотография и не географическая карта.

Существующий React/Vite-проект с интерактивным атласом, синхронизированной хронологией, архивным столом и анимированными разделами.

## Запуск

```sh
npm install
npm run dev -- --host 127.0.0.1
```

Production-сборка: `npm run build`. Проверка сборки: `npm run preview`.

## Проверки

`npm run test:cinema` проверяет все новые режимы на 1440×1000 и 390×844, сохранение отметок после перезагрузки, завершение и повтор фильма, reduced-motion и ошибки JavaScript. Снимки второго прохода: `artifacts/*-v4.png`.

`npm run test:details` проверяет перетаскивание разрыва эпох, перемещение и сброс архивного материала, удержание фокуса в модальном режиме, переход по маршруту, ширины 768 и 1920 px. Дополнительно выводит локальную выборку интервалов кадров при скролле; это диагностический замер headless Chrome, а не гарантия FPS на других устройствах.

При запущенном dev-сервере на порту 5173 выполните `npm run test:visual`. Требуется установленный Google Chrome. Тест проверяет desktop и mobile: карту, слои, приближение, полноэкранный режим, общую дату, архивный поиск, фильтры, просмотр материала, отсутствие горизонтального переполнения и режим reduced-motion. Снимки сохраняются в `artifacts/`.

`npm run optimize:images` пересоздаёт WebP из сохранённых исходных PNG. Интерфейс использует облегчённые WebP.

`npm run test:motion` дополнительно проверяет сравнение карты, воспроизведение этапов и паузу вне экрана, сохраняет снимок scroll-сцены. Условия запуска те же, что у визуального теста.

## Статус материалов

Изображения — художественные ИИ-реконструкции, схема карты условная, архивные листы демонстрационные. Они подписаны в интерфейсе и не выдаются за подлинные фотографии или документы. Исторический контент и источники требуют отдельной редакционной проверки перед публичным использованием в качестве справочника.

Анимации учитывают `prefers-reduced-motion`; автопроигрывание карты приостанавливается вне экрана и при скрытой вкладке. Декоративный pointer-параллакс отключён для touch-устройств.
